# 05 — خارطة الطريق

## المرحلة 0 — التأسيس (أُنجزت في هذا التسليم)

- [x] وثيقة رؤية ومعمارية وميزات وعتاد.
- [x] هيكل مشروع `apps/web` + `services/api` + `workers`.
- [x] خادم FastAPI + SQLite + طابور مهام + SSE.
- [x] واجهة عربية RTL: الرئيسية، الاستوديو، الطابور، المكتبة، الإعدادات.
- [x] محرّك تجريبي يولّد فيديو حقيقياً (FFmpeg/Pillow).
- [x] محوّلات ComfyUI محلي/بعيد + Hugging Face Space (جاهزة للتهيئة).
- [x] سكربتات تثبيت وتشغيل على Windows.

**معيار القبول:** `.\scripts\run.ps1` يفتح الواجهة، وإنشاء توليد يعرض فيديو في المكتبة خلال أقل من 20 ثانية على المحرّك التجريبي.

## المرحلة 1 — MVP حقيقي (2–3 أسابيع)

| المهمة | معيار القبول |
|---|---|
| توصيل ComfyUI محلي | توليد 5s/512p من نص بنموذج LTX بنجاح |
| دفتر Colab/Kaggle | رابط نفق يعمل، وتوليد من التطبيق عبره |
| صورة → فيديو | رفع صورة + وصف → فيديو يبدأ من الصورة |
| مكتبة أصول | معاينة، تنزيل، حذف، بحث، مصغّرات |
| إعدادات المحرّكات | إضافة/اختبار/اختيار افتراضي، حفظ آمن |
| تحسين الأمر | زر «حسّن الوصف» بقوالب عربية |
| سجل الأخطاء | سبب واضح بالعربية + إعادة محاولة |

## المرحلة 1.1 — الصوت والأفاتار (2 أسابيع)

- edge-tts مع اختيار صوت عربي وسرعة ونبرة.
- دمج التعليق على الفيديو + خفض الموسيقى تلقائياً.
- LatentSync/Wav2Lip: صورة + صوت → فيديو ناطق.
- تفريغ تلقائي وترجمة (Whisper) وحرق الترجمة.

## المرحلة 1.2 — التحرير والتكبير (2 أسابيع)

- تايم لاين حقيقي (سحب، قص، ترتيب، مدة).
- انتقالات وطبقات نص.
- Real-ESRGAN / RIFE كخطوات لاحقة للتوليد.
- موسيقى بالوصف (ACE-Step) — اختياري حسب العتاد.
- مساعد الإخراج (LLM عبر Ollama) لتوليد قائمة مشاهد.

## المرحلة 2 — الاحترافية (شهر+)

- اتساق الشخصية: صور مرجعية + LoRA + إدارة نماذج.
- فيديو → فيديو بقناع (VACE) وتمديد المشاهد.
- قوالب مشاريع (إعلان، ريلز، شرح، قصة).
- تصدير متعدد المقاسات دفعة واحدة.
- نسخ احتياطي/استعادة للمشروع كاملة.
- وضع «معرض» للمقارنة بين النسخ (A/B).

## المرحلة 3 — متعدد المستخدمين (اختياري)

- مصادقة، مساحات عمل، حصص.
- Postgres + Redis + عاملون منفصلون.
- نشر Docker مع دليل أمان.

## ما لن نفعله (قرارات نطاق)

- تدريب نماذج أساسية من الصفر.
- بث مباشر.
- استنساخ صوت أشخاص دون موافقتهم (سياسة أخلاقية صريحة).
- مولّد نص داخل الفيديو (نستخدم طبقات نص في المونتاج).

## طريقة العمل المقترحة

1. **أسبوع التثبيت:** نشغّل Colab ونولّد أول فيديو حقيقي.
2. **دورات أسبوعية:** ميزة واحدة مكتملة + اختبار + توثيق.
3. **قاعدة:** لا تُضاف ميزة قبل أن تعمل سابقتها من الواجهة حتى التصدير.
