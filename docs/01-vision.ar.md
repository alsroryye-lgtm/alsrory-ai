# 01 — الرؤية والمنتج

## المشكلة

صناعة الفيديو بالذكاء الاصطناعي اليوم محصورة بين أمرين:

1. **خدمات سحابية مدفوعة** (Sora، Veo، Kling، Runway، HeyGen…): جودة عالية لكنها اشتراكات شهرية، وحصص، وسياسات استخدام، وبياناتك عندها.
2. **أدوات مفتوحة متفرقة** (ComfyUI، Wan، LTX، LatentSync…): قوية ومجانية لكنها موجهة للمهندسين: إعدادات عقدية، سطر أوامر، ولا وجود لتجربة «مشروع ومونتاج ومكتبة».

**alsrory.AI** يسدّ الفجوة: يقدّم تجربة منتج متكامل (مشاريع، استوديو، طابور، مكتبة، مونتاج) فوق نماذج مفتوحة المصدر، مع محرّك قابل للتبديل حتى لا يرتبط التطبيق بجهاز واحد.

## المستخدم المستهدف

- **المرحلة الأولى:** مستخدم واحد (المالك) على جهاز Windows، يريد تجربة احترافية محلية.
- **لاحقاً:** صنّاع محتوى عرب، فرق صغيرة، ومعلمون — عبر نشر ذاتي بسيط.

## المبادئ الحاكمة

| المبدأ | القرار العملي |
|---|---|
| **Local-first** | الخادم والواجهة يعملان على 127.0.0.1. لا حساب، لا تتبّع، لا سحابة إجبارية. |
| **مفتوح بالكامل** | لا مكوّن مغلق في المسار الأساسي. حتى النماذج قابلة للاستبدال. |
| **لا قفل على مزوّد** | كل توليد يمرّ عبر `Engine` protocol. إضافة مزوّد = ملف واحد. |
| **الفشل مرئي** | كل مهمة لها حالة وتقدّم وسجل أخطاء واضح بالعربية. |
| **العربية ليست ترجمة** | الواجهة RTL أصلية، والمصطلحات مكتوبة للمستخدم لا للمهندس. |
| **قابل للتشغيل بلا GPU** | المحرّك التجريبي يجعل كل شاشة قابلة للتجربة والاختبار. |

## ما الذي يميّز alsrory.AI عن غيره؟

### مقابل الخدمات السحابية
- مجاني بلا حصص.
- يعمل دون إنترنت بعد تنزيل النماذج.
- لا رقابة على المحتوى إلا ما تفرضه النماذج نفسها.
- يمكنك الاحتفاظ بالبذرة (Seed) والإعدادات وإعادة إنتاج النتيجة حرفياً.

### مقابل ComfyUI وحده
- مشاريع ومشاهد بدل ملفات JSON متفرقة.
- طابور مهام مع تقدّم، إلغاء، وإعادة محاولة.
- مكتبة أصول موحّدة (فيديو، صور، صوت) مع معاينة.
- مونتاج وتصدير جاهز للمنصات.
- واجهة عربية بلا عقد.

### مقابل أدوات المونتاج
- التوليد داخل سياق المشروع، لا ملفات تُنقل يدوياً.
- إعادة استخدام الشخصيات والأسلوب (Consistency) في كل المشاهد.
- مساعد إخراج يحوّل الفكرة إلى قائمة مشاهد قابلة للتنفيذ.

## تجربة المستخدم — الرحلة الأساسية

```
فكرة
  │
  ▼
مشروع جديد ──► مساعد الإخراج (قائمة مشاهد + أوامر محسّنة)
  │
  ▼
استوديو التوليد
  ├─ نص → فيديو
  ├─ صورة → فيديو
  ├─ فيديو → فيديو
  └─ أفاتار (نص + صورة + صوت)
  │
  ▼
طابور المهام (Queued → Running 40% → Completed)
  │
  ▼
مكتبة المشروع (Take 1، Take 2…)
  │
  ▼
المونتاج (تايم لاين، صوت، ترجمة)
  │
  ▼
تصدير MP4 (9:16 / 16:9 / 1:1)
```

## مؤشرات النجاح (للنسخة 1.0)

| المؤشر | الهدف |
|---|---|
| إنتاج فيديو 5 ثوانٍ 720p محلياً | ≤ 6 دقائق على GPU 12GB |
| إنتاج نفس الفيديو عبر Colab مجاناً | ≤ 12 دقيقة (مع الطابور) |
| نسبة المهام الفاشلة بسبب التطبيق | < 3% |
| الوقت من الفكرة إلى أول مشهد | < 3 دقائق |
| تغطية الواجهة بالعربية | 100% |

## خارج النطاق (الآن)

- بث مباشر (Live streaming).
- تعاون فوري بين عدة مستخدمين.
- تدريب نماذج من الصفر داخل التطبيق (يُدعم LoRA لاحقاً).
- تطبيق جوال أصلي (الواجهة متجاوبة أولاً).
