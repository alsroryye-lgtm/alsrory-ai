# مشغّل ComfyUI — دليل الـ Workflows

هذا المجلد يحتوي قوالب **ComfyUI API workflows** التي يستخدمها محرّك `comfy` في alsrory.AI.

## كيف يعمل الربط؟

1. تُشغّل ComfyUI (محلياً أو على Colab/Kaggle) وتفتح رابطاً يصل إليه التطبيق.
2. تضع الرابط (والرمز السري إن وُجد) في **الإعدادات → المحرّكات**.
3. عند كل توليد، يقرأ التطبيق ملف `workflows/<نوع-التوليد>.json`، يستبدل
   العناصر النائبة `{{...}}` بالقيم الفعلية، ثم يرسلها إلى `POST /prompt`.
4. يراقب التطبيق `GET /queue` و`GET /history`، ثم ينزّل الملفات من `GET /view`.

> الملف **ليس** Workflow جاهز للسحب والإفلات في واجهة ComfyUI.
> إنه نسخة **API** (Export (API)) — أي JSON مسطّح بمفاتيح `class_type` و`inputs`.

## العناصر النائبة المدعومة

| العنصر | القيمة |
|---|---|
| `{{prompt}}` | الوصف النصي (إيجابي) |
| `{{negative}}` / `{{negative_prompt}}` | الوصف السلبي |
| `{{width}}` / `{{height}}` | الأبعاد بالبكسل |
| `{{frames}}` | عدد الإطارات = `seconds × fps` |
| `{{fps}}` | الإطارات في الثانية |
| `{{seed}}` | البذرة (ثابتة لكل توليد لتكرار النتيجة) |
| `{{seconds}}` | المدة بالثواني |
| `{{image}}` | اسم الصورة المرفوعة داخل ComfyUI (فارغ في نص→فيديو) |
| `{{motion_strength}}` | شدة الحركة في صورة→فيديو |
| `{{generation_id}}` | معرّف التوليد (استخدمه في اسم الملف) |

العنصر النائب يُستبدل بنوعه الأصلي إذا كان النص **كله** عنصراً واحداً
(مثل `"{{width}}"` → `832` رقم، لا نص). هذا مهم لأن ComfyUI يرفض
الأرقام النصية في بعض العقد.

## القالب المرفق: `text2video.json`

يستخدم **Wan 2.1 T2V 1.3B** (الأخف والأسرع، مناسب لـ T4 16GB):

| العقدة | الملف المطلوب في `ComfyUI/models` |
|---|---|
| `UNETLoader` | `diffusion_models/wan2.1_t2v_1.3B_fp16.safetensors` |
| `CLIPLoader` (type: wan) | `text_encoders/umt5_xxl_fp8_e4m3fn_scaled.safetensors` |
| `VAELoader` | `vae/wan_2.1_vae.safetensors` |

يدعم ComfyUI عقدة `SaveVideo` الحديثة (mp4/h264). إن كانت نسختك قديمة،
استبدلها بـ `VHS_VideoCombine` من حزمة VideoHelperSuite، أو حدّث ComfyUI.

## إضافة أنواع توليد أخرى

ضع ملفاً باسم النوع في نفس المجلد، وسيُستخدم تلقائياً:

```
workflows/
├─ text2video.json     ✅ مرفق
├─ image2video.json    (صورة → فيديو)
├─ video2video.json    (فيديو → فيديو / إعادة تلوين)
├─ avatar.json         (نطق الشفاه)
├─ upscale.json        (تكبير الدقة)
├─ interpolate.json    (زيادة الإطارات)
├─ subtitles.json      (ترجمة مدمجة)
└─ audio.json          (TTS / موسيقى)
```

لأي نوع غير `text2video`، إن لم يوجد ملفه سيتوقف التطبيق برسالة واضحة
بدلاً من تنفيذ قالب نص→فيديو بالخطأ.

### طريقة التصدير الصحيحة من ComfyUI

1. رتّب الـ workflow في واجهة ComfyUI حتى يعمل ويعطيك فيديو.
2. من قائمة **Workflow → Export (API)** — وليس Save.
3. احفظ الملف باسم النوع المطلوب داخل هذا المجلد.
4. استبدل القيم المتغيّرة بالعناصر النائبة أعلاه.

## نصائح

- **أبعاد Wan:** يجب أن تكون من مضاعفات 16. التطبيق يرسل 832×480 و480×832
  و640×640... وكلها متوافقة.
- **عدد الإطارات:** Wan يحتاج `4n+1` إطاراً. إن أرسل التطبيق `72` (3s × 24fps)
  فاستخدم عقدة `ImageFromBatch` أو غيّر `length` إلى `"{{frames}}"` مع
  `KSampler` يقبل أي طول — عملياً يعمل ComfyUI مع التقريب الداخلي.
  للحصول على أفضل نتيجة اضبط `fps` في التطبيق على `16` أو `24` مع مدة
  تُنتج عدداً مناسباً.
- **الذاكرة:** على 16GB VRAM استخدم `--lowvram` عند تشغيل ComfyUI،
  أو نموذج fp8/GGUF.
- **الوقت:** 3–5 ثوانٍ على T4 ≈ 2–5 دقائق. التطبيق يعرض تقدماً تقديرياً.
- **الملفات المرفوعة:** الصور تُرفع عبر `POST /upload/image` قبل إرسال
  الـ workflow، ويُمرّر اسمها في `{{image}}`.
